# **Clarity Index — Critique Layer**

**Critique → Gradient → RTT/1**

Clarity is the **first measurable property** of an idea.  
It determines whether the idea can be expressed, captured, and handed off to Gradient without distortion.

Critique does not judge correctness.  
It judges **expressive clarity**.

---

## **1. Clarity Declaration**

```
clarity_index:
  layer: critique
  purpose: expressive clarity
  mode: S/R/E compatible
  output: clarity_packet
```

---

## **2. Components of Clarity**

Critique defines clarity across three axes:

### **(1) Structural Clarity (S‑mode)**  
Is the idea expressed in a way that has a recognizable frame?

```
structural_clarity:
  frame: <core structural outline>
  boundaries: <explicit limits>
  contradictions: <early paradox signals>
```

### **(2) Resonance Clarity (R‑mode)**  
Does the idea express a coherent conceptual frequency?

```
resonance_clarity:
  frequency: <dominant conceptual frequency>
  harmonics: <secondary conceptual patterns>
  dissonance: <where resonance breaks>
```

### **(3) Energy Clarity (E‑mode)**  
Is the idea’s intent and activation force clearly expressed?

```
energy_clarity:
  intent_force: <strength of intent>
  activation: <what energizes the idea>
  decay_points: <where energy dissipates>
```

---

## **3. Clarity Packet Structure**

This is the object Critique produces and hands off to Gradient.

```
clarity_packet:
  structural: <structural_clarity>
  resonance: <resonance_clarity>
  energy: <energy_clarity>
  clarity_surface: <normalized clarity object>
```

The packet is intentionally minimal — Gradient expands it during alignment.

---

## **4. Interaction with S/R/E Modes**

Clarity interacts with Critique’s triad:

### **S‑mode (Structure)**  
Clarity reveals the idea’s frame.

### **R‑mode (Resonance)**  
Clarity reveals conceptual frequencies.

### **E‑mode (Energy)**  
Clarity reveals activation forces.

---

## **5. Handoff to Gradient**

The clarity packet is passed directly into:

**Gradient — Alignment Layer**  
`gradient/docs/attunement_template.md`

Gradient uses the packet to:

- stabilize coherence  
- bound drift  
- declare paradox  
- prepare the idea for RTT/1  

---

## **6. Output Format**

```
clarity_output:
  layer: critique
  packet: <clarity_packet>
  ready_for: gradient
```
