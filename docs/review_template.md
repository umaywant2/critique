# **Review Template — Critique Layer**

**Critique → Gradient → RTT/1**

A review in Critique is not an evaluation.  
It is a **clarity extraction pass** — a structured reflection that reveals the idea’s shape, intent, contradictions, and boundaries.

This template ensures every idea receives a consistent, upstream‑safe review before entering Gradient.

---

## **1. Idea Overview**

```
title: <idea title>
summary: <1–3 sentence description>
intent: <what the idea wants>
```

---

## **2. Structural Review (S‑mode)**

```
structural_review:
  frame: <core structural outline>
  boundaries: <explicit limits>
  contradictions: <early paradox signals>
  notes: <additional structural observations>
```

---

## **3. Resonance Review (R‑mode)**

```
resonance_review:
  frequency: <dominant conceptual frequency>
  harmonics: <secondary conceptual patterns>
  dissonance_points: <where resonance breaks>
  notes: <additional resonance observations>
```

---

## **4. Energy Review (E‑mode)**

```
energy_review:
  intent_force: <strength of intent>
  activation: <what energizes the idea>
  decay_points: <where energy dissipates>
  notes: <additional energy observations>
```

---

## **5. Boundary & Paradox Surface**

```
boundary_surface:
  explicit_limits: <list>
  implicit_limits: <list>

paradox_surface:
  early_signals: <list>
  tension_points: <list>
```

---

## **6. Clarity Assessment**

```
clarity_assessment:
  structural: <low | medium | high>
  resonance: <low | medium | high>
  energy: <low | medium | high>
  overall: <low | medium | high>
```

---

## **7. Clarity Packet Draft**

This is the object handed off to Gradient.

```
clarity_packet:
  structural: <structural_review>
  resonance: <resonance_review>
  energy: <energy_review>
  clarity_surface: <normalized clarity object>
```

---

## **8. Ready for Gradient**

```
handoff:
  layer: critique
  packet: clarity_packet
  next: gradient
```
